NEXUS ULTRON — Նախապես միացված Supabase

Սովորական օգտատերը NEXUS-ում լրացնում է միայն email-ը և գաղտնաբառը, հետո սեղմում Create account։ Supabase URL-ն ու publishable key-ը ծրագրում արդեն կարգավորված են։ Secret key-ը հավելվածում չկա։

ՔՈ ՄԵԿԱՆԳԱՄՅԱ ՔԱՅԼԸ՝ տվյալների բազան պատրաստելու համար

1. Բացիր քո Supabase նախագիծը և մտիր SQL Editor։
2. Բացիր այս փաթեթի payload/supabase_schema.sql ֆայլը, ամբողջ SQL-ը պատճենիր SQL Editor, սեղմիր Run։
3. Դրանից հետո օգտատերերը կարող են անմիջապես գրանցվել NEXUS-ից։ Հաշիվները երևում են Authentication → Users, պրոֆիլները՝ Table Editor → nexus_profiles, իսկ զրույցները՝ nexus_messages։

Եթե Auth-ում email confirmation-ը միացված է, օգտատերը հաստատում է իր email-ը ստացած նամակից և հետո մուտք է գործում։ Սա Supabase Auth-ի կարգավորումն է։

RLS կանոնները յուրաքանչյուր գրանցված հաշվին թույլ են տալիս աշխատել միայն իր տվյալների հետ։ Ծրագրում օգտագործվում է միայն public publishable key։ Secret/service_role բանալին երբեք մի ավելացրու հավելվածի մեջ։

Նախկին փորձնական `nexus_messages` աղյուսակ արդեն ստեղծվա՞ծ է `user_id text` սյունակով։ SQL-ը չի ջնջում այդ տողերը. դրանք տեղափոխելու կամ աղյուսակը թարմացնելու համար նախ առանձին backup արա, հետո կարգավորիր schema-ն։
